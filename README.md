# Kaggle-Competitions

Combined Kaggle competition solutions. One folder per competition, each with its
own README covering the problem, the approach and the result.

- [Playground Series S6E7 — Health Risk Prediction](Playground-Series-S6E7-Health-Risk-Prediction/) — 3-class tabular classification on balanced accuracy. A 434-spec local model zoo, ~34 Kaggle GPU/CPU kernels (RealMLP / FT-Transformer / TabM / TabPFN / TabNet), and nested-CV-audited ensembling. Public LB 0.95070, rank 379/2852 at the 2026-07-26 snapshot.
- [ROGII — Wellbore Geology Prediction](ROGII-Wellbore-Geology-Prediction/) — geosteering: predict TVT along a horizontal well's lateral from its Gamma-Ray log, trajectory and a nearby vertical reference well.
- [Neural Debris Removal in Streak Detection Models](Neural-Debris-Removal-in-Streak-Detection-Models/) — ESA "Secure Your AI" machine-unlearning competition; de-poisoning a backdoored RetinaNet streak detector. Final: 208.1281 maCADD, rank 61/614.
- [Autonomous Agent Prediction (Beta)](Autonomous-Agent-Prediction-Beta/) — Kaggle-in-Kaggle: the submission is an *agent config* that must solve an unseen binary-classification task alone inside a 60-minute offline container. Includes an offline replica of a full session used to measure every change on the 16 labelled tasks. Public 0.822 / private 0.780, rank 141/570.
- [Pokemon TCG AI Battle Challenge](Pokemon-TCG-AI-Battle-Challenge/) — The Pokemon Company x Kaggle agent ladder: a policy that plays full 60-card Pokemon TCG games inside the organizers' simulator under hidden information and shuffle randomness. Includes the seeded common-random-number harness that made small policy gains measurable, and the full record of what was rejected. Best public score 844.4, final agent line 794.3.
